MINUS – NY REN VERSION

Filer:
- index.html: hela appen (design + funktion) i en enda fil
- manifest.json: inställningar för att lägga till på iPhone-hemskärmen
- icon-180.png och icon-512.png: appikoner
- sw.js: tar bort gamla cache-filer om den gamla versionen hade en service worker

Publicera:
1. Packa upp ZIP-filen på datorn.
2. Öppna GitHub-repot Tool-Length-Calculator.
3. Ta bort/ersätt gamla filer i repots rot med filerna här.
4. Se till att index.html ligger direkt i roten, inte i en undermapp.
5. Commit changes och vänta på GitHub Pages.
6. På iPhone, öppna Safari och gå till https://kvarti4.github.io/Tool-Length-Calculator/ . Uppdatera sidan.
